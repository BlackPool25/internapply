# internship-freelancing-v2-nuke-rebuild - Work Plan

## TL;DR (For humans)

**What you'll get:** A nuke-and-rebuild internship discovery engine that finds Bangalore DevOps/backend roles from ~140 real ATS boards + Hirist + Unstop + free no-auth APIs (Arbeitnow/Remotive/TheMuse as overflow) + Internshala, all via Postgres on Docker internal network with a queued, rate-limited pipeline — plus one-click truthful resume tailoring only when you type `/tailor`, and a frontend where every source has its own colored badge and filter.

**Why this approach:** Two load-bearing pivots from brutal research + Momus audit (16 SearxNG searches, 2026-09-01): (1) LinkedIn guest caps at page 10/IP with routine 999 bans, so it stays overflow-only with a circuit breaker, while ATS-direct JSON (Greenhouse/Lever/Ashby/SmartRecruiters) is keyless and reliable — no proxy needed. (2) Batch LLM tailoring burns ₹66k/mo, so the pipeline is truncated to `discover→filter→save` and tailoring moves to an on-demand `opencode` skill (1 cached LLM call). Exhaustive Wave 0 spike gates everything — if 140 boards + free APIs don't prove live, we don't write code.

**What it will NOT do:** No LLM in batch, no cover letters in batch, no paid Apify/RapidAPI for LinkedIn, no auto-submit LinkedIn Easy Apply (ToS ban risk — safe external link only), no Playwright in discovery, no Upwork scrape/blast at 0 reviews, no hardcoded 200 slugs in code, no SQLite as primary (Postgres now), no raw HTML jd_hash, no Celery+BullMQ double-queue (keep arq).

**Effort:** Medium (4-5 days, 15 todos + 1 exhaustive spike)
**Risk:** Medium — Hirist endpoint drift + LinkedIn 999 + 140 probe 25-30% 404 need spike; mitigated by circuit breaker + dead letter + retry-after+jitter
**Decisions to sanity-check:** (1) Keep arq (native async) vs switch to Celery (decided: keep arq, your override honored); (2) Postgres 16 (matches compose) not 17; (3) Free supplemental APIs as Tier3 overflow not Tier1 (remote EU/US feeds filtered to near-zero for Bangalore narrow).

Your next move: Approve → `$start-work` executes in waves (Wave 0 spike gates all). Momus brutal review already incorporated — see fixes B1-B10 in todos.
